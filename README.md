
# DevOps Lab

## Description
This project is a simple HTML webpage created to practise Git and GitHub. It demonstrates version control, commits, branching, merging, and collaboration using a GitHub repository.

## Project Structure
- `index.html` — The main webpage.
- `README.md` — Project description and instructions.

## How to Run
1. Download or clone the repository.
2. Open the project folder.
3. Double-click `index.html` to open it in your web browser.

## Technologies Used
- HTML
- Git
- GitHub
